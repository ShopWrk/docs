Automations run the follow-up you should not have to remember. A missed ShopWrk call can get a text. A Facebook lead form can create the contact and tag them. An Instagram comment can get a public reply.

Open **Automations** to see what you already have. When you create one, ShopWrk opens the builder. There is no setup screen before the canvas.

Messaging, lead forms, and calling only fire if those pieces are already connected. [Instagram and Messenger](/integrations/social-media#connect-instagram-and-messenger) and [Facebook Lead Ads](/integrations/social-media#connect-facebook-lead-ads) start on **Settings → Integrations**. ShopWrk calling is your shop phone, not a separate phone vendor.

## The builder

The editor is a two-pane workspace.

The left pane is the canvas, where steps sit in order. The right pane opens when you click a step or click **ShopWrker**.

The header has back, **Builder**, **Activity**, **Settings**, publish, and **ShopWrker**.

<CardGroup cols={2}>
  <Card title="ShopWrker" icon="sparkles">
    Ask ShopWrker to draft the workflow. It has to pick a real trigger, such as Instagram Message Received, Meta Lead Form, or Missed inbound call. New automations do not get one combined message trigger.
  </Card>
  <Card title="Write with AI" icon="pen">

  </Card>
</CardGroup>

Publish from the header when the workflow is ready. ShopWrk will not publish a Meta Lead Form or ShopWrk Form Submitted trigger until you pick exactly one form.

## How a workflow is built

Each automation has a trigger, optional filters, and actions.

The trigger is the event that starts it. Filters decide whether this contact should continue. Actions are the work: send a text, send an email, add a tag, wait, or send information to another tool you already use.

Actions run in order. Put a wait between them when you want breathing room, like a same-day text and a next-day email.

## Message and comment triggers

These are separate triggers. There is not one "message received" item for new automations.

- **SMS Received**
- **Email Received**
- **Instagram Message Received**
- **Facebook Message Received**
- **Instagram Comment Received**
- **Facebook Comment Received**

Reply actions are split the same way. **Reply to Instagram Comment** and **Reply to Facebook Comment** are two separate steps you can add.

Instagram DMs and Facebook messages need the [Instagram & Messenger connection](/integrations/social-media#connect-instagram-and-messenger) on Integrations first. Those threads also land in Conversations, on the same contact.

<Note>
  Instagram and Messenger automations can send for up to 7 days after the customer last wrote in. After 7 days, ShopWrk will not send. See [how long you can reply](/integrations/social-media#how-long-you-can-reply).
</Note>

## Calling triggers

These use **ShopWrk calling**. They are three separate triggers, not one call step with a dropdown.

- **Missed inbound call** fires when an inbound call is not answered. It does not also fire Call ended.
- **Voicemail left** fires when the caller leaves a voicemail. That is not a missed call and not a call ended.
- **Call ended** fires after an answered call hangs up.

## ShopWrk Form Submitted

**ShopWrk Form Submitted** is its own trigger. You must pick exactly one ShopWrk form. There is no "any form" option, and you cannot leave it blank.

If you change the form, ShopWrk asks you to confirm, then clears field mappings for the old form.

Draft and test submissions do not run live automations. Only a real submission on that form does.

## Meta Lead Form

**Meta Lead Form** is a different trigger from ShopWrk Form Submitted. That is the name on the step. It is not labeled Facebook.

You must pick exactly one Facebook lead form. Publish is blocked until that form is set.

Connect Facebook Lead Ads first. See [Instagram, Messenger, and Facebook Lead Ads](/integrations/social-media). Then pick that form on this trigger. Changing the form confirms and clears mappings, same as ShopWrk forms.

When that form is submitted, the person lands in ShopWrk as a lead. The automation can then **Add Tag**, send a text, or move them through the rest of your follow-up.

<Tip>
  If the form list is empty, import the Facebook lead form in Forms first. The Facebook Lead Ads connection lives on Integrations. The import is not in this builder.
</Tip>

## Tags

**Add Tag** and **Remove Tag** are the tag actions. Add and remove are separate. New automations cannot replace every tag in one shot.

If an older automation still used replace-tags, it will not publish until you rebuild that part with add and remove.

## Start from another tool

Two pieces stay in the builder for shops that already use other software.

**Start from another tool** is a trigger. Another tool you already use can tell ShopWrk to start this automation.

**Send info to another tool** is an action. It sends info to another tool you already use.

You set both on the automation itself.

## Other shop events

You can also start automations from everyday shop work: a new contact or lead, a deal moving, an estimate sent or approved, a job changing status, an invoice paid, a booking request, or a warranty coming due. Those sit alongside the message, calling, and form triggers above.

## Turn one on, pause it, or check how it ran

The automations list shows whether each workflow is on, what starts it, and whether runs are failing.

Use **Builder** to edit steps. Use **Activity** to see runs. Use **Settings** for the name and whether it is on. You can pause one without deleting it.

Old automations that used one combined message trigger are moved onto the matching channel when ShopWrk can tell which channel it was. If it cannot tell, that step is marked incomplete so you can pick SMS, email, Instagram, or Facebook yourself.
