If you want ShopWrker to remember shop rules, go to **Settings → AI & Automation → ShopWrker → Memory**.

Save them once. ShopWrker uses that list when you chat on **AI**, and when ShopWrker shows up on other screens such as Lead Closer. You do not paste the same rules into every conversation.

If you still have an old Memory bookmark under **AI**, ShopWrk sends you to this settings screen.

## Memory vs other knowledge

These are different places. Do not mix the names.

**Memory** is this tab. Short shop facts, plus notes that are only about you.

The **knowledge library** is the files the assistant can read. Put price sheets, PDFs, film spec sheets, and longer writeups there. See [AI assistant](/features/ai-assistant).

**Vault** is where you save logins and keys ShopWrker can use when you ask it to work on a site. Secrets stay hidden after you save. See [Vault](#vault) below.

**Lead Closer Knowledge (this agent only)** is that agent's playbook knowledge. It is not this Memory list. See [Lead Closer](/features/lead-closer).

If ShopWrker should answer from a short rule without opening a file, put it on **Memory**. If it is a document someone would print or attach, put it in the knowledge library. If ShopWrker needs a login to a dealer portal or similar, put it in **Vault**.

## Shop memory

Shop memory is shared. ShopWrker treats these as the shop's rules in chat: goals, promotions, constraints, and standing notes.

The list is a table with **Fact**, **Type**, **Source**, and **Updated**. Types you can pick are **Goal**, **Promotion**, **Constraint**, and **Standing note**.

<Steps>
  <Step title="Add a shop fact">
    Click **Add shop memory**. Choose a **Type**. Give it a short name in **Key**. Write the wording in **Fact**. The fact text is what ShopWrker uses. Save it.
  </Step>
  <Step title="Fix or remove one">
    Open the row menu. **Correct** replaces the wording. ShopWrker uses the new fact. **Remove** stops ShopWrker from using it. Your personal notes stay.
  </Step>
</Steps>

A customer text does not rewrite this list.

## Personal notes

The **Personal** card is only yours. ShopWrker uses it when it talks to you. It does not become a shop-wide rule.

Click the card to add or edit notes. Long notes get cut off on the card. Click it again to read the full text. **Clear** wipes your personal notes for this shop. Shop memory stays.

## How ShopWrker uses this in chat

Open **AI** in the sidebar and type like you always do. ShopWrker already has the shop memory list and your personal notes. Ask it to draft a follow-up, price a job, or explain how you run weekends, and it should follow what you saved here.

The same shop memory is in play on Lead Closer. Set it once on this tab.

If ShopWrker needs a yes or a choice from you, it asks in the same chat box. You do not get a second window.

## Vault

If you want ShopWrker to reuse a login you already trust, go to **Settings → AI & Automation → ShopWrker → Vault**.

Vault sits next to **General**, **Memory**, and **Connected apps**. You only see the tab if your access allows owning credentials or using shared ones. If the tab is missing, ask an Owner to grant use of shared credentials under [Team access](/getting-started/roles-permissions).

Vault is for saved logins and keys. **Connected apps** is for signing into Google, Notion, QuickBooks, or Zoho on that app's own screen. Do not mix them.

### What you see

| Section | What it is |
| --- | --- |
| **Your credentials** | Logins and keys you added. You can edit, share, disable, or delete. |
| **Shared with you** | Use-only access a teammate shared. You can use it with ShopWrker. You cannot see the secret, edit it, or share it again. |

Each row shows the name, websites, type, optional account label, and last used. After you save, the password or key is never shown again. The row says **Saved** when you edit, with a **Replace** button if you need a new secret.

### Add a login

<Steps>
  <Step title="Open Vault">
    Go to **Settings → AI & Automation → ShopWrker → Vault**.
  </Step>
  <Step title="Add credential">
    Click **Add credential**. **Type** defaults to **Login**. You can also pick **API key**. **Card** is not typed in here. Cards are saved through your payment setup under Connected apps when that path applies.
  </Step>
  <Step title="Name it and save">
    Enter a **Name** you will recognize (for example XPEL Dealer Portal). Optionally add **Websites** like `xpel.com` (press Enter or the plus control). For a login, enter **Username or email** and **Password**. Optional **Account label** helps when you have more than one account. Click **Save credential**.
  </Step>
</Steps>

Edit later from the row menu (**Edit**). Keep the stored secret, or click **Replace** to type a new one. **Disable** stops ShopWrker from using it without deleting. **Delete** ends assistant access and any shares. Deleting does not sign you out of the website itself.

### Share with a teammate

From **Your credentials**, open the row menu and click **Share**.

The dialog says they can use it but cannot see it, edit it, or share it. Pick a teammate and click **Share**. Revoke with the trash control on that person.

If nobody is eligible, the picker says to grant use of shared credentials in Team access first.

Payment-type rows do not offer Share.

### How ShopWrker uses Vault in chat

When you ask ShopWrker to work on a site that matches a saved credential you own or one shared with you, ShopWrker can reuse that login instead of asking you to type it again.

If several logins could match, ShopWrker shows choices for you to pick. Weak or unclear matches do not auto-pick. Secrets still never appear in the chat.

### Walkthrough: save a dealer portal login

Priya's shop orders film through a dealer portal. She wants ShopWrker to open that site without pasting the password every time.

1. She goes to **Settings → AI & Automation → ShopWrker → Vault** and clicks **Add credential**.
2. She leaves **Type** on **Login**, names it "XPEL dealer", adds website `xpel.com`, enters the shop username and password, and saves.
3. She shares it with her office manager as use-only so they can ask ShopWrker the same way.
4. On **AI**, she asks ShopWrker to check an order on the dealer site. ShopWrker uses the saved login. Neither of them sees the password again in Vault or in chat.

### Vault gotchas

- **Secrets stay hidden after save.** There is no "show password" on a saved row. Use **Replace** if you need a new secret.
- **Vault is not Connected apps.** Google and similar stay under **Connected apps**.
- **Shared means use-only.** Teammates never see or reshare your secret.
- **Tab visibility follows access.** No Vault tab usually means your permission group cannot own or use shared credentials yet.

## Connected apps

If you want ShopWrker to read or take actions in apps you already use, go to **Settings → AI & Automation → ShopWrker → Connected apps**.

Connected apps lets ShopWrker work in accounts like Google, Notion, QuickBooks, or Zoho when you ask in chat. ShopWrk never sees that app's password. You sign in on that app's own sign-in screen.

### Connected apps vs Google Calendar sync

These are easy to mix up. They are not the same setting.

| Place | What it is for |
| --- | --- |
| **Settings → AI & Automation → ShopWrker → Connected apps** | Lets ShopWrker read and take actions in Google (Gmail, Calendar, Drive, Contacts, Ads, website stats) and other apps when you ask in AI chat |
| **Connections → Google Calendar** | Syncs your shop calendar so jobs and appointments show on the calendar you already use. See [Google Calendar](/integrations/google-calendar) |

Use Connected apps when you want ShopWrker to pull from Gmail or Drive in a chat. Use **Connections → Google Calendar** when you want the shop schedule on Google Calendar.

### Who can manage Connected apps

You need the **Settings Integrations** permission. If you cannot open the tab or connect an app, ask someone with that permission.

### Connect an app

The **Connected apps** tab lists the pilot apps: **Google**, **Notion**, **QuickBooks**, and **Zoho**.

- **Google.** ShopWrker can read and take actions in your Gmail, Calendar, Drive, Contacts, Ads, and website stats when you ask.
- **Notion**, **QuickBooks**, and **Zoho.** ShopWrker can read and take actions in that account when you ask.

<Steps>
  <Step title="Open Connected apps">
    Go to **Settings → AI & Automation → ShopWrker**, then open the **Connected apps** tab.
  </Step>
  <Step title="Start the connection">
    Click the plus button on the app you want. ShopWrk opens that app's sign-in screen. Sign in there. ShopWrk never asks for that password on its own screen.
  </Step>
  <Step title="Finish or retry">
    When sign-in works, the app shows as connected. If you leave early or sign-in fails, you see a warning. Click the plus button again, or **Sign in again**, to retry.
  </Step>
</Steps>

If app connections are not ready for your shop yet, the page says **App connections are not set up yet. Check back soon.**

### Manage tools after you connect

When a connection is healthy, open **Manage** on that app. ShopWrk opens a detail page titled **Connected apps** for that account.

On the detail page, each tool has three choices:

| Choice | What it means |
| --- | --- |
| **Never** | ShopWrker cannot use that tool |
| **Ask first** | ShopWrker shows an approval card each time (default when you have not saved a choice) |
| **Always allow** | ShopWrker runs that tool without asking |

The tools list can be empty until ShopWrk finishes the first connection check. Wait a moment, then refresh the page if it stays blank.

**Uninstall** confirms, then removes access right away. ShopWrker cannot use that app until you connect it again.

### How Connected apps show up in chat

When ShopWrker uses a connected app while you chat on **AI**, you may see status like **Using Gmail**. Results can show a line such as **From Google** so you know where the answer came from.

If a tool is set to **Ask first**, approve or deny in the same chat before ShopWrker continues.

### Walkthrough: connect Google for ShopWrker

Maria runs a wrap shop. She wants ShopWrker to find a customer's last email in Gmail when she asks about a lead.

1. She goes to **Settings → AI & Automation → ShopWrker → Connected apps**.
2. She clicks plus on **Google** and signs in on Google's screen.
3. She opens **Manage**, leaves Gmail tools on **Ask first**, and sets Drive tools she does not need to **Never**.
4. On **AI**, she asks ShopWrker to find the last email from Jordan about a Tesla wrap. ShopWrker shows **Using Gmail**, asks once, then answers with **From Google**.

Her shop calendar sync stays under **Connections → Google Calendar**. That sync is separate from this Google connection for ShopWrker.

## General

**General** is **AI Action Mode**. This tab opens first.

**Ask Permission** shows you the change and waits. ShopWrker does not send a message, reschedule a job, or edit shop data until you approve.

**Autonomous** lets ShopWrker do those actions without asking. Use that only if you already trust it.
